# Hackathon Project

A small Express.js application.

## Getting Started

```bash
npm install
npm start
```

For development with auto-reload:

```bash
npm run dev
```

## Configuration

Copy your environment variables into a `.env` file at the project root. This file is git-ignored.

## Project Structure

- `app.js` — application entry point
- `routes/` — route handlers
- `views/` — EJS templates
- `public/` — static assets
